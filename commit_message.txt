1.14.442: one kernel.conf for both laptops; lfs-kernel disable

- lfs-kernel: with FIRMWARE_BUILTIN in use, the firmware the BUILDING
  machine's built-in drivers need is added for that build: amdgpu by the
  GPU's PCI id (Raven .. Strix Halo APUs), btusb by an Intel radio's USB
  id (8265 .. AX211), AMD microcode by CPU family -- so the P14s profile
  built on a T14 (Renoir, AX200) still brings up its GPU and Bluetooth.
  An AMD GPU it does not know is named, with what to do
- lfs-kernel disable <name>: takes a name's (or a machine's) symbols out
  of CONFIG_SET and its patterns out of FIRMWARE_BUILTIN
- the built-in firmware patterns are no longer globbed by the shell
